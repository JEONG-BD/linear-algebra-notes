# 1.2 소거법 
## 소거법 
- 일차 연립 방정식을 푸는 간단한 방법은 소거법(eliminiation method)이다. 
- 연립 방정식 내의 한 방정식에서 하나의 미지수를 없애기 위해 다른 방정식에 적당한 값을 곱한 다음 해당 방정식에 더해준다. 
- 위의 과정을 필요한 만큼 반복하여 어떤 방정식이 하나의 미지수만 갖도록 하면 ${ax=b}$ 의 형태를 얻을 수 있다. 
```math
\begin{cases}
3x - 2y = -1 \\
x + y = 3 
\end{cases}
```
```math
\begin{cases}
x + y = 3 \\
3x - 2y = -1 
\end{cases}
\\

\begin{cases}
x + y = 3 & (\times 2)\\
3x - 2y = -1
\end{cases} 
```
```math
= \begin{cases}
2x + 2y = 6 \\
3x - 2y = -1
\end{cases} 
``` 
```math
\begin{aligned}
5x = 5 \\  
x = 1 \\
y = 2 \\ 
\end{aligned}
```

- 소거법은 다음 세 가지 연산을 이용하여 주어진 연립 방정식을 변화시켜 동일한 해집합을 가지면서 보다 풀기 쉬운 형태의 연립방정식으로 변환해 나가는 방법이다. 
  > 1. 두 방정식을 교환한다.   
  > 2. 한 방정식에 0이 아닌 상수를 곱한다. 
  > 3. 한 방정식에 임의의 상수를 곱하여 다른 방정식을 더한다. 
- 위의 세 가지 연산을 방정식에 관한 세 가지 기본 연산(elementary operation)이라고 한다.  

## 불능의 해를 가지는 경우 
```math
\begin{cases}
3x + 3y = 6 \\
4x + 4y = 12 
\end{cases}
```
## 부정의 해를 가지는 경우 
```math
\begin{cases}
3x + 2y = 6 \\
6x + 4y = 12 
\end{cases}
```
